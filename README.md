<h1>use guide</h1>

<b>1. clone</b>
```
git clone https://github.com/raxxer160/commit-farmer-script.git

```
<b>2. run the script</b>
```
cd commit-farmer-script
python3 main.py
```
<b>3. complete the configuration</b>
<br>example
```
no configuration found
repo url/ssh (must end with .git): git@github.com:user/repo.git
minimal time between commits (minutes, def 30): 20
maximum time between commits (minutes, def 90): 120
```
>[!note]
>to change the config
>
>edit the config.txt
>
>or delete it and run the script
